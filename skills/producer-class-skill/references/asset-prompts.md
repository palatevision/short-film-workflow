# 固定资产生成提示词

用于人物、场景和道具的静态资产提示词。**新写实人物/场景没有其他已确认画风时，默认采用下列固定写实基底；已定动画/其他风格、已有资产与本次明确要求优先。** 换题材、服装或地点不自动更换质感基底，也不批量重做已有素材。

## 固定质感段

把下段完整融入本次人物/场景资产正文，不只写一个风格名称：

> 超写实真人实拍质感，真实材料具有自然纹理与粗糙度变化，反射克制，接触阴影自然；主体与背景有清楚的空间层次，无3D渲染或游戏引擎质感。

人物另补：皮肤保留自然毛孔、细小绒毛与肤色差异，高光柔和，不做蜡质磨皮；按本角色可见设定保留痣/红血丝等特征。无人场景与道具省去皮肤句。

固定光线/空间要求：优先自然侧光或侧逆光、阴影侧观察、真实材料受光与接触阴影，轮廓清楚；窗光/天光、薄雾与主辅点缀色可按目的选择，有需要时落实60:30:10的具体配色。夜间或已定灯具使用实际场景光源，不能又要求仅天光。强逆光/薄雾遮住身份结构时，改为柔和侧光、简洁背景，保住可辨识性。8K/IMAX仅作尺度/精细感参考，不承诺真实分辨率。

静态资产不带24fps、180度快门、持续运镜、动态微表演、全程移动或声音要求；画幅按交付用途。道具/状态/结构图优先形制、比例、材质和清晰轮廓，不强套薄雾、深暗、浅景深或人物双栏。相关动态摄影材料见[摄影表达示例](cinematography-examples.md)。

## 人物：先身份结构，再造型与视图

助手按下列顺序填好本次内容，给一整段可复制词，不能把空模板交用户填写：

1. 真实参考绑定：哪张锁身份/生物结构，哪张只借服装/姿态；无参考不编图号。
2. 主体与造型：年龄阶段、可见体型、服装颜色/剪裁、允许持物；不夹人物弧光分析。
3. 固定结构与可变状态：头身比例、五官/特殊器官、关键轮廓、嘴开合及服装/道具状态，哪些不能变、哪些可变分别写清。
4. 材质：皮肤、织物、金属或生物表面的实际纹理/光泽，融合完整固定质感段及人物补充。
5. 版式与取景：承接已确认角色板格式；需要时用横向双栏，左约40%半身、右约60%正侧背全身，同一身份和比例。原本没脸就不强加五官，不给每个资产强制三视图。
6. 本次光色与背景：按视图功能选清楚光线、具体颜色和画面边界。

## 场景与道具：按用途输出完整提示词

**场景**：真实参考用途→场地几何/入口/窗户/固定物位置→材料→本次光源方向/时段与具体色彩→机位/画幅/清晰范围→允许状态与画面边界，融合完整固定质感段。场景母图不自动加人/道具，固定布局和光向清楚，反向视图按实际需要补。

**道具**：真实参考用途→形制/部件/比例→材质/磨损→完好或变化状态→实际所需视图/取景及清楚背景→光线与关键保持项。固定写实基底中只取适合道具的材料/受光/空间描述，不能因人像基底增加皮肤或服装。

## 生成后怎样用

新资产先对照用户认可样本，看身份/形制、皮肤/反射、光线层次、接触与空间可信度，再扩同组；按项目需要用少量代表镜头看进入视频后的变化。已有问题按授权局部修，不新增逐镜首帧前置。改图保留采用父本与状态变体，不继续用明显漂移版本作唯一参考；进入视频后仍按[共同格式](prompt-delivery.md)写该镜动作/摄影/声音。

这套结构由既有参考绑定、固定结构/可变造型、材料与功能视图做法整理而来；具体角色造型不跨项目照搬。固定基底是创作约定，尚不能据文字保证跨模型稳定效果。
