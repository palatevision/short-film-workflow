# 制作联动与积累

## 与现有影视Skill一起用

专业模块可独立主导，总控按需要补课程判断。先识别当前阶段，选择一个主要负责人并按需接续，不同时加载全部模块。优先从技能列表找到所需模块。分镜模块未列出时，直接打开[同合集的分镜入口](../../short-drama-storyboard/SKILL.md)，再按该模块的相对路径读取所需参考。只有技能列表和实际文件路径均不可读时，才报告该模块当前不可用，并按本轮可用资料继续。

联用时承接本项目既有稿件、目录与命名，不因模块示例写EP001就把普通短片重建成剧集。模块工具确有固定输入时，说明需要怎样适配；不能声称未满足输入的脚本已成功。

用户只要设定就不自动写媒体词，只要词就不自动生成；明确请求生成时才接可用生成工具及其Skill。沿用当前项目生成方式，补课件知识不增加付费、发布、批量重做或每镜首帧任务。

## 从当前稿推进到下一份可用结果

**故事/剧本**：承接已定事实、可变范围、人物目标/关系和结构/情绪要求，交足以讨论的故事稿或被请求场次。AI可共同找点子、试写和修对白，不设纯人工原始创意限制。对白看是否符合人物、改变关系/信息、重复画面；改稿打转时撤掉不必要假设，比较真正不同的方向，再合回有效部分，不默认另开对话或换付费模型。写作任务书可讨论主题和情感；生图/视频词另按[正文语言](prompt-language.md)转成画面。

**分镜讨论**：默认先完整草案，再逐镜讨论。镜号、估计剪辑取用、动作、景别/运镜、声音与接镜可一起通读；对开场/揭示/转折/高潮/结尾带具体方案对齐观感，不把每个普通参数都变成提问。只补某镜就保留其他已定部分。长对白按立场、信息和关系变化分配镜头，不强制每句切镜或每场物件交接。

**资产/提示词**：反复出场、换造型或复杂道具时补实际所需视图/状态；已有参考足够就复用，不凑三视图。区分包装/拆封、完好/损坏等状态，保留基础版与变体。认可的声音在授权范围记录音色来源及采用版，新对白按当前稿，不照搬源背景声。全片有效风格进入每镜完整复制段，具体规则只维护在[共同格式](prompt-delivery.md)和[风格参考](cinematography-language.md)，单镜也不能让用户拼补丁。

**样片/粗剪**：用户说“不对劲”即可，结合实际片段、参考/设置与上下镜定位。区分叙事/剪辑成立和画面/美术成立，按[视觉规划](visual-planning-and-edit.md)检查；单张好看不等于动态/接镜通过。缺媒体时只给初步判断和必要缺口，不编可见证据。先用现有可用区间完成任务，再按实际缺口补镜；一个候选的前段与另一候选的末段可采用，但核身份、光线、动作和声音接得上并记来源/入出点。

仅末尾动作失败时，可提出能接回的短片段/独立镜，给进入状态、需完成动作、退出状态和余量；生成能力按入口，不把“一秒取用”当能生成一秒。合理变速也需核对白/口型。已花生成成本不构成保留废镜理由，改词就交完整新版；涉及主线/人物/结局或已定画风的改变另作提案。

## 难点测试、交接与停止条件

从本项目最影响成立的难点选代表场面，说明目标、可观察采用条件和备用表达；有测试授权再执行，不要求凑固定数量。用本项目资产和准备投产的模型/设置核验；低成本原型只验证过结构就只报告结构，不把另一工具成功或旧版本经验当当前已过。新发现有价值的构图/表演可记候选，不自动覆盖故事。

节奏、对白或空间拿不准时，用已有文字/图/声音作轻量时间线，找缺口，不为预演强制生图。跨场/序列在原记录承接人物已知信息、关系、服装、持物、空间/光源及必要画外声；合理时间/信息跳跃可保留，不要求所有镜头无缝续拍。混制按[保留/变化与参照](hybrid-live-action.md)选择路线，不能只检查相机路径而漏表演和接触关系。

镜头表或现有记录保留最终采用媒体、父本/参考、完整词、模型/设置、偏差/取舍；多人项目再加执行/复核人。角色/场景状态变体不覆盖原版。项目目标、职责/反馈和进度取舍集中按[项目协作](project-production.md)，内容目的按[目标与受众](content-goals-and-audience.md)，不再各建一套审批表。

一场已有少量可用素材就可试粗剪，已达成本场信息/表演任务就停，缺具体反应或衔接才定向补。到时间/成本边界仍未满足，带备用表达和影响给负责人选择，不无限重跑。记录有效、无明显差异、不稳定和待验证；尽量一次改一类关键变量，矛盾基线先纠正。格式/文件检查与实际媒体效果分别报告。

## 声音从当前阶段加入

声音承担信息、表演与空间时，按[声音叙事](sound-design.md)从当前分镜或时间线补关键声源、听觉焦点与进退；生成词仍集中到共同格式的“声音”。实际素材、原生声音能力和后期任务分清，不为每镜另建表，也不把文字设计当已混音。

## 音乐主导与叙事主导分开处理

MV/视觉实验先看创意是否适合音乐段落；确认主题/歌词方向和足以支撑本片的音乐后，按实际音频安排情绪、视觉事件、重音与收尾。歌词可变成行动、世界规则或图形，不必逐词配图。文字时间码不证明已卡点；波形帮助定位，不能代替听音乐/对白。音乐主导可先定声音，叙事戏不默认先铺配乐。

可见主唱唱歌需对照已定音频和词序；歌曲作外部配乐时，人物按剧情行动，不因歌词响起就开口。模型原生声音/口型与实际入口核验。严格交付/多人协作/关键因果锁定时以前置分镜明确范围；获授权探索的MV可以先测代表性风格/动态，再调分镜，保住已定身份/故事，不把偶然好看变成新剧情。

选音乐除情绪，还听可截取段落、重复、重音/句尾和余量。悬疑中判断音乐是在预警、误导还是给环境/反应留空间；降低或移后配乐有时更合适，不能每个转折都加音效或每镜卡重拍。保留对白与关键声响可懂性。[Artlist音效库](https://artlist.io/sfx)是用户收藏入口，未选具体素材或订阅；使用时核对应授权，未确认它就是老师展示网站。

## 课程和真实项目怎样回填

完整资料、只有录音或只有转写，都按[案例融通](case-to-method.md)处理覆盖、来源和疑点；用户没听课/没标重点时也从完整可读材料主动提炼，不让用户先做摘要。普通收录已授权，不建立后台同步或扩大外发/生成范围。

按[案例融通](case-to-method.md)区分课堂说法、助手迁移和实作效果；重复补出处，条件不同补边界，新能力才考虑新资源。不因讲师提开源就安装全部仓库，不把当下建议倒写成历史项目真实流程。更新后核共享真源/发现链接和既定格式，简报新增判断、疑点与验证范围。

历史镜头抽样、用户动作范例、课程定位及未验证范围集中在[课程证据](course-evidence.md)和对应项目资料；它们支持持续校准，不让实际执行每次重读按日期堆叠的课程复述。
