# 镜头语言：影像质感与摄影选择

把用户希望的画面转成可见的光色、材质、机位、视野、景深、对焦和运动。按当前故事、全片画风与镜头职责选择，直接融入提示词；不要求用户先选一个风格名或拼前后缀。参数细查[摄影库](photography.md)，示例段见[摄影表达](cinematography-examples.md)。

## 从镜头任务选手段

| 当前任务 | 可用的摄影判断 | 本镜检查 |
| --- | --- | --- |
| 想要胶片颗粒、克制色彩与柔和高光 | 在风格段写实际颗粒、色彩、高光和黑位；Vision3可作参考 | 不连带强制同一机位、青蓝色、黑脸或固定光圈 |
| 远处观察、跟踪、窥视 | 较远机位配长焦，按需前景遮挡与浅景深 | 必须读清的表情/道具别被遮挡或虚掉；机位距离与透视关系成立 |
| 近身对峙、狭窄环境挤压 | 较近机位配广角，保留环境、尺度与清晰关系 | 不叠长焦压缩；深景深、胸口高度与手持按信息需要选择 |
| 需要严格说明摄影行为 | 分开机位、视野/焦段、焦点、清晰范围、构图、路径与稳定性 | 固定与移动、绝对零漂移与手持不得自相矛盾 |
| 写实资产或质感缺口 | 按[固定资产规范](asset-prompts.md)建立材料、受光与层次 | 已有风格/资产优先，图像不带视频时长/声音 |
| 需要防止失真/色偏/错误文字 | 用本镜实际约束收束清晰度、色彩、状态与输出 | 只写有效项，不统一禁止剧情应出现的文字、音乐或变化 |

## 组合顺序与交付

先明确观众必须看见/听见什么，承接画幅、资产、生成方式和全片基底；再选观察距离/视点/稳定性，确定清晰对象，最后选相容光源、摄影与声音。它们可分别取用，不因借用颗粒就附带整套禁令。需要改变已认可风格、故事或资产时交提案；普通摄影实现直接给建议。

已选的全片基底完整进入每镜“风格”，机位与焦段等进入“摄影参数”，状态和易错点进入“必要约束”；按照[共同格式](prompt-delivery.md)交一段完整正文。摄影目的在段外，正文写实际画面。独立镜头不写“同上”。

## 视野与清晰范围的参考

在36×24mm全画幅、对角线约43.27mm的假设下，f＝D÷[2tan(对角视场角÷2)]：18°约136.6mm，84°约24.0mm。实际画幅/裁切不同须重算；提示词标全画幅等效，视场角不是光圈。以下数值为可选表达参考，不是全片固定参数。

| 维度 | 远距长焦观察 | 近距广角与环境挤压 |
| --- | --- | --- |
| 距离/视野例子 | 6—8m、对角18°，约135—137mm等效 | 0.8—1.2m、对角84°，约24mm等效 |
| 摄影机/镜头 | 按项目选一套；柔和焦外需配合真实取景/清晰要求 | 先看近距离体量与环境，不堆器材品牌 |
| 景深/焦点 | f/1.8可作浅景深参考，眼睛/指定对象清楚 | f/8—f/16可作较深景深参考，人物和必要环境可辨 |
| 前后景 | 背景较收束，前景可有约25%—40%遮挡，但不能挡关键动作 | 前景体量突出，周边环境共同构图，不搭长焦散景句 |
| 运动 | 固定或极慢微移是候选 | 带重量的肩扛/轻微呼吸起伏是候选，也可依任务固定 |

景别、画幅、视野和焦段分别描述。长焦可以是多种景别，16:9也可拍长焦特写。光圈数值不能保证全部清楚，先定义需要清楚的范围。

## 先解冲突，再写完整词

- 光源矛盾：按已确认的场景/主风格选，必要时只问主次；不同时承诺仅天光与人工主光。
- 浅景深与背景线索：调整景深、对焦、站位或拆镜，不同时要求背景全虚又人人可辨。
- 180度动态模糊与高速水珠冻结：按当前冻结需求选快门观感，说明取舍，不把两者当同一曝光配置。
- 绝对固定与肩扛呼吸：选择固定或可控起伏，不叠互斥描述。
- 黑位/暗脸与表情：为必读信息保留局部亮度层次，不机械套黑脸。
- 无配乐/字幕的例句与已定声音/文字：以本片要求为准，不删除已经确定的后期设计。

## 三个摄影决策片段

以下只说明摄影选择，不代替最终九栏目视频词。

**街对面观察**：当前风格基底，机位约7m，全画幅等效135mm视野；需要浅景深时以f/1.8为参考，眼睛清楚、背景收束，画面下方约三分之一柔化遮挡。固定机位；道具若需看清，再调整焦点/景深，不硬保仅眼睛清晰。

**狭小房间对峙**：约1m机位，胸口高度略仰拍，24mm等效广角全景/中景按信息取；人物前景体量突出，墙面/天花板/必要线索可辨。以较深景深为视觉目标，手持幅度按本镜选；不叠长焦压缩或柔美人像背景。

**自然窗光与柔和背景**：以窗侧逆光分离人物，50mm或85mm等效视野按取景选，必要时f/1.8浅景深参考；眼睛与关键物件均可辨，背景柔化。真实材料、接触阴影和光源关系保持，不因清晰度参考词再堆多套机身。

组合后核色彩/曝光、距离/焦段、清晰范围/线索、主体/相机运动、帧率/模糊是否相容。输出具体描述和完整词；文字/字段通过不等于模型执行或实际画面验收。
