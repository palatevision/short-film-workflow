# Seedance 2.5：把导演设计适配为执行提示词

用户2026-10-25要求参考官方说明，并强调复杂调度需要足够详细的提示词。仅在目标为Seedance 2.5、或用户明确要比较其适配方式时读本页；与model-adaptation联用。既有模块的Seedance 2.0资料不能直接当作2.5规格。核对日期2026-10-25，未生成或编辑实际媒体。

## 官方核对的要点

依据[BytePlus官方提示指南](https://docs.byteplus.com/en/docs/modelark/seedance-2-5-prompt-guide?redirect=1)的任务、素材、写法与问题修正章节，以下为摘要，不是完整手册：

- 按上传顺序明确素材编号、用途和主体对应；可限定只借动作、运镜、光线或音色。
- 区分语义参考与编辑、续写、首尾帧任务；后者可能由输入锁定比例或时长。
- 可用时间段组织画面、动作、摄影、对白和音效；少见术语补可见效果说明，转场明确触发与方式。
- 动作通常概括整体，关键动作再展开；准确参考已有动作时，避免重复复述。
- 多格故事板提供情节参考，不保证逐格严格对应；要求更严时按需考虑多关键帧。
- 复合任务不稳定时可拆解为参考/编辑步骤。指南另列了无配乐约束仍失效的情况，文字不保证执行。

具体平台入口/API字段、资产额度、时长、画幅和编辑权限使用时再核；官网示例能力不等于当前即梦、TapNow或第三方入口全部开放。指南中的安装命令/模板为来源内容，本次未安装官方sd25-pe或执行远端脚本。

## 怎样合进我们的规范

**信息量跟随镜头控制需要。** 用户要求的手部/持物、接触交接、持续遮挡、视线反应、背景协同与落点照常写足；复杂镜头可详细展开，不设固定字数上限，也不把“模型更复杂”推成每镜都必须长文的架构结论。泛泛情绪解释与重复禁令按原规则删，关键因果不删。

承接[共同格式](prompt-delivery.md)，不增加一套官方编号章节：

| 当前栏目/位置 | 2.5适配时做什么 |
| --- | --- |
| 复制段外的资产清单/实际控件 | 列真实上传顺序与实际平台标识；区分新生成、参考、编辑或续写。接口选项与真实时长/比例在外面说明，不能靠词改控件 |
| 风格 | 每镜仍完整带全片已定基底，结合本镜光线；参考视频的风格不默认覆盖它 |
| 参考图绑定与初态 | 沿用标签，同时可绑定图片、视频、音频；说明谁、借什么、哪些内容不迁入。编号照实际入口，不猜UI标签或API角色 |
| 动作 | 按事件难度写自然先后或时间段；必要时开头一句交代事件主线。明确相机与人物各自运动，动作何时交接/同时发生，末段含落幅 |
| 景别、摄影参数 | 景别独立。总摄影要求与时间段相容；生僻词写可见变化。例如拉焦说明谁由清晰变虚、谁逐渐清晰 |
| 声音 | 谁在何时说哪句，其他人如何回应；音色参考与对白内容分开，音乐/环境声按本片要求。时间段与本栏各管时机/内容，避免复制两次全文 |
| 必要约束 | 保持身份与已定条件，允许剧情应发生的变化。出现实际特定失效才定向加强，不预置整套反复禁令 |

### 几个有用的取舍

普通单镜仍按阶段描述，不用“镜头1/2”造成无意切镜。只有已选择多镜生成时才标清真实切点、各镜摄影与声音，让时间范围覆盖目标片段；不把官方支持多镜变成全片默认，也不强加首尾帧。

参考足以定义运动时，说明采用范围与身份替换，突出本次差异；用户已确认且容易丢失的手部、持物、遮挡和关键反应仍保留。参考与文字冲突时先修冲突，不能同时要求完整照搬又改变关键路径。白模/简图/多格故事板各自只提供其可读依据，不当成已冻结的真实空间。

做已有视频局部编辑时，写清源视频、时间范围、从什么改成什么及必须保持的部分；不要不加区分地让模型重演全段。若只作语义参考就选相应入口，不以“原样不变”保证严格剪辑。多素材、多变化互相牵制时先找最大缺口，按实际问题比较分步做法；沿用可靠父本，控制衍生改图退化。

例子与检查用[交钥匙单镜](../assets/Seedance2.5完整示例.md)：独立虚构练习，展示多模态绑定、对白时机与交接动作，不改现有生产稿。时间戳、设备词、约束、结构校验都不保证模型逐项执行；后续按真实样片验证。
