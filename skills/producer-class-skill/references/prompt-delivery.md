# 视频提示词统一交付规范

2026-10-24，用户用《剪影师》开场逐项审阅后确认本页格式，覆盖0.7.0要求把五段编号交给模型的规定。老师的五段思路和陈坤六维继续用于内部组织、检查；课程方法、详细动作、摄影判断、风格预设及当前生成方式保持。**本页是唯一现行交付结构。**

## 最终交付

复制段外简短列镜号/名称、真实资产挂图顺序及必要的提案状态、实际平台设置。随后给一个完整复制段，不让用户自己拼词或填写JSON。

复制段固定按下列简单标签组织；不输出“01输入资产／02风格与绑定”等章节编号，不再单独重复绑定、落幅或一致性章节。这里是助手填写指引，最终须用具体内容替换占位说明。

```text
时长：生成时长。
画幅：

风格：当前项目画风、光色与材质。

参考图绑定与初态：实际图片编号、资产名及本镜用途；主体身份、起始站位/姿态/持物、必要空间关系。

动作：
0—X秒：具体起始动作。
X—X秒：后续及协同动作、接触/遮挡/反应。
X—结束：最后的动作＋落幅，写清最终人物、道具、构图与焦点状态。

景别：独立列出，说明画面取到哪里。

摄影参数：机位、等效焦段/视野、光圈/景深、对焦、构图与运镜。

声音：环境音、音效、逐字对白；无对白/配乐按本镜明确。

必要约束：本镜易错点、身份/服装/道具/空间/光线保持项，以及实际必要的输出边界。
```

镜号是复制段外的索引；预计剪辑使用时长也放外面，与生成时长分开，没有已定取用长度就不编。时长/画幅保留为正文创作要求，实际模型、分辨率等仍是工具控件，文字不能代替设置。

## 怎样填，才方便直接使用

- **风格**：全片确定的有效风格基底，完整进入每镜可复制提示词的“风格：”，不能只存在视觉设定、只给一个风格名字、写“同上”或让用户另找粘贴。把统一色彩、材质、影像质感及必要摄影倾向写成可复用的具体描述，再结合本镜光源/时段；全片一致不等于每镜同一灯位、曝光、景别或焦段。与当前场景冲突的昼夜/光线条件按已定场景适配，不能机械复制。风格摄影方案按[镜头语言](cinematography-language.md)选择相容内容，直接写具体光色、材质与摄影；不自动叠整套胶片前缀或固定观察方案，不靠“高级／电影感”堆词。
- **参考图绑定与初态**：合并参考映射、身份和开始的画面。只列真实提供/实际将挂载的资产，图片编号与顺序相符，说明每张取用范围。无参考时写“无参考图”及初态，不为凑栏目新建资产，也不编上一镜尾帧编号。
- **动作**：简单命名为“动作：”；按时长和事件安排时间段，段数由动作决定，不固定三段、五段或等分。单个简单动作可自然顺序描述。保留构成目标画面的先后/协同、持物、视线、持续遮挡、速度和停顿，不用“转身／递东西”代替必要过程。镜内时间段不自动表示切镜。
- **落幅**：写在最后一个动作时间段的末尾，与最后动作连在一起。说明末态位置、持物、动作完成度、相机/焦点停在哪里；清楚即可，不另抄一段“落幅”。若没有时间段，则接在动作末句。与下一镜起态对照，不增加强制尾帧图片，也不编未知后续。
- **景别**：始终单独标“景别：”，不埋入摄影参数。取景范围与主体占比清楚；需要变化时在动作中同步写起止景别。
- **摄影参数**：写成一段清楚的摄影描述，内部检查机位、焦段/视野、景深/清晰范围、对焦、构图、路径与稳定性是否齐全且相容。相机品牌/型号、镜头系列是可选视觉参考，默认省略，不输出“未指定品牌”等占位句。焦段默认注明全画幅等效；精确f值非必须，需要的是清楚的景深要求。参数是视觉参考，不保证模型真实模拟设备。
- **声音**：集中写本镜实际声音，不附带给人的后期安排或模型能力解释。原生声音/字幕/参考语法按所选工具核验；未核实不声称支持。配乐、对白、字幕是否允许按项目，不统一强制无声或无字。
- **必要约束**：合并保持项、允许剧情变化和本镜易错点，同一限定写一次。剧情要开门/断裂/落物，就不能又用“所有状态全程不变”封死它们。有合同/招牌时不能同时禁止所有文字。

导演目的、解释、建议状态、平台限制、后期说明在复制段外；正文描述可见画面、动作、光线、空间和声音。精简说明与重复限定，不能精简掉目标动作。

## 内部融合与风格联用

老师的输入资产→风格绑定→分时画面→衔接落幅→一致性检查继续作为组织思路。陈坤六维（景别、角度、运镜、空间、内容、落幅）用于展开与复核，最终都汇入上面的简单栏目，用户拿到一份完整结果。

颗粒、高光、黑位、观察距离、视野与稳定性按[镜头语言](cinematography-language.md)与[摄影表达](cinematography-examples.md)选择，融入本镜风格、摄影和必要约束；静态资产按[固定资产提示词](asset-prompts.md)。不再维护命名风格入口；摄影与参考冲突按当前目的处理，实质改变已定方案时说明并讨论。

风格尚未确定时，可由style-cinematography-director结合故事/观感提出少量方向和可复制风格段；需要比较实际风格帧时联用short-drama-image-prompts，确认后复用统一基底。不要每镜重新选全片风格，也不把写词等同出图验收。

## 单镜、多镜与生成方式

默认承接项目已定逐镜/多图直出方式；不因老师的15秒三镜示例改全片生成单位或增加首尾帧前置。

单镜给完整一段，时间阶段都在“动作”里。已明确选择多镜生成时，公共风格和绑定只写一次；“动作”内按时间范围与镜号逐镜写动作、景别、摄影、声音、末态，在对应切点写具体承接，不用“同上”丢控制，也不另起五段模板。每镜摄影不同就放在各镜中，不能再写互相冲突的统一摄影。时间范围覆盖总片段，切镜与连续动作阶段分清。末镜的最后动作写全段落幅。

示例：[单镜完整示例](../assets/分镜到提示词完整示例.md)、[多镜片段示例](../assets/多镜片段完整示例.md)。均未生成媒体；单镜是用户已认可的格式样本，多镜为手工离线演示。

## 先用已有信息，再处理缺口

读取当前故事、分镜、视觉设定和最新反馈，沿用已定时长、资产与对白。摄影写法由助手按镜头职责提出，正文外必要时标为建议，不让用户逐项填表。最终确实缺少无法推断的剧情、参考映射或执行设置时集中问；探索稿可标提案，不把未知当事实。

景别、画幅、焦段、距离、对焦和景深共同描述同一画面；先决定需要清楚的区域，再选参数。拉焦不等于相机移动；原位细微手持与绝对锁定零漂移有区别。源图构图、轴线、手部/道具与初态相容；参考图里的其他人物不必入画。时长装不下动作/反应/对白就提出延长或拆镜，不偷省关键动作或默认加速。

故事、资产、分镜、摄影、模型适配和诊断可由合适专业Skill独立主导，最后都遵守本页共同交付格式。沿用当前生成方式，不从某片的英文对白或多图直出推成全项目规则；已有生产稿按授权局部修改。

## 内部装配与验证范围

[单镜装配器](../scripts/assemble_video_prompt.py)是可选辅助，不增加用户操作。schema 5保留显式style、shot、assets、prefix/body/common_tail/consistency_tail、sound、binding。body由助手写完整动作与落幅；旧transitions可选兼容，若提供就接在动作末尾，不再单独输出。shot.camera_lens改为可选；其余摄影结构字段帮助检查，输出合并为“摄影参数”，景别仍单列。镜号和edit_seconds只进入内部报告，预计剪辑时长不混入复制段。

完整输入见[JSON样例](../assets/video-prompt-example.json)。assets仍为slot/name/use列表，空列表用于无参考；style仅用project，风格/摄影/必要约束由助手按项目完整填写，程序不注入整套预设。旧版project输入的字段和最终九栏目保留；已撤销的命名预设入口不再接受，所需内容先融入项目文本。工具只检查字段、基本数值与引用槽位，不判断语义落幅、时序/光学或模型效果，多镜仍手工组织。

```sh
python3 <skill目录>/scripts/assemble_video_prompt.py --input /private/tmp/镜头.json --output /private/tmp/镜头提示词.md --report /private/tmp/镜头检查.json
```

交付前确认：绑定在开头、动作足够且最后包含落幅、景别独立、摄影相容、声音/必要约束集中、风格未串用，用户仅凭资产清单和正文即可操作。字段检查、人工内容复核、实际媒体效果分别报告。
