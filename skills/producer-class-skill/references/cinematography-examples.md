# 摄影表达示例

这些是可选的摄影表达材料，用于把具体视觉效果写入已确认的项目；不是独立风格入口，也不自动追加到所有镜头。最终按[共同格式](prompt-delivery.md)合进一段完整提示词，参数与本镜信息任务相容。以下保留既有光色、材料、观察方式和运动/声音内容，旧版的全局启用口令已撤销。

## 冷峻纪实的胶片光色

柯达 Vision3 500T 胶片，增感一档；全画面细腻真实胶片颗粒，实景光源边缘带有轻微光晕。阴影偏青蓝压暗，高光向琥珀色偏移，中间调降饱和，黑位压缩；不做数字磨皮清理，无美化补光。所有光线仅来自场景内实景光源 —— 裸钨丝灯、雨水柔化的霓虹光、显示器背光、透过湿玻璃的汽车大灯。人物面部可部分乃至完全沉入阴影。曝光优先保留主光源层次，不以人物主体为曝光基准。无 CG 光泽感，无游戏引擎质感，拒绝平正面柔光。芬奇 + 维伦纽瓦式冷峻纪实影像美学。

这是具体影像方案，只有与已定画风和本镜信息相容时采用。要读清表情/道具时保留其必要亮度层次；夜间实景光、日间窗光和曝光优先级不能机械并列成矛盾要求。

## 远距长焦观察

镜头后缀 — 监控长焦：对角线视场角 18°，经典长焦镜头特性，机位距离拍摄对象 6 至 8 米。强烈的背景压缩效果，远景景物层层堆叠在人物身后。刀刃般极浅景深，仅锁定双眼与核心面部特征清晰，其余全部消融在柔和暗散景中。画面观感如同远距离窥视：狗仔偷拍、监控视角、猎物被追踪的氛围。必须带有前景遮挡：模糊前景物体占据画面下方 25%–40% 区域，呈现大块暗色散景轮廓。相机固定机位，或极其缓慢微移，无快速摇镜。镜头与人物之间悬浮着大气薄雾。无广角畸变，不使用正面主光。本镜头绝不采用常规全景 / 宽幅取景。

本段“必须/绝不”仅描述这一示例的选择，不是其他镜头的规则。景别和画幅另按项目明确；关键背景/道具要看清时调整景深/遮挡。压缩关系须结合机位距离判断，固定机位单换焦段不等于透视改变。

## 近距广角与环境挤压

镜头后缀 — 近距离压迫感：对角线视场角 84°，经典广角镜头特性，机位距离拍摄对象 0.8 至 1.2 米。轻微低角度，镜头高度对齐人物胸口或下巴，机位绝不高于人眼。前景人体体量感大于真实比例；人物四周环境清晰可见，从画面边缘向内挤压。全画面纵深清晰，墙、天花板、杂物全都锐利真实。无长焦压缩效果，无柔美的人像散景。环境是囚笼，而非单纯背景。手持肩扛拍摄：带有肩扛设备的重量感，细微呼吸起伏、微小晃动，没有稳定器那种顺滑悬浮感。本镜头绝不出现长焦效果，也不使用平淡正面取景。

同样按镜头目的取用；固定机位或更温和的表演可成立，不要求所有狭小空间手持。与远距长焦是两种观察选择，不在同一时段叠成互相矛盾的相机。

## 清晰度与输出边界

主体锐利清晰，保留原生胶片颗粒，无锐化伪影；色彩保持已确认的青蓝阴影、琥珀高光和低饱和中间调，不发生无依据的色偏。

无字幕/无叠加配乐只在本次生成明确需要时写进必要约束；项目已有字幕、音乐或画内文字时保留。原内部色彩编号不代替上述具体描述。

## 自然光写实摄影与动态参考

- 画面：超写实真人实拍，真实材料与接触阴影，无3D渲染或游戏引擎质感；8K/IMAX可作清晰/尺度参考，不能代替实际输出设置。
- 光线：自然侧逆光、阴影侧观察、天光/窗光和大气薄雾可组合为一套具体方案；该方案不使用人工补光。夜间灯具或结构设定图按已确认光源/清晰目的适配，不能同时要求仅窗光又指定人工主光。
- 色彩：有需要时把主色/辅助色/点缀色约60:30:10落实为具体颜色，不把比例强加所有画面。
- 皮肤与物理：保留毛孔、绒毛、不对称痣、红血丝等可见细节，阴影贴合光源；物体有重量，受重力/惯性影响，接触处有真实支撑，不悬浮。
- 表演：可写反应前短停顿、自然视线、眼睛高光和呼吸起伏，按具体角色需要取用，不靠“好莱坞级”保证效果。
- 构图与连续：三分法、黄金分割和前中后景是候选手段；人物/道具/场景状态连续，已有行动需要时自然移动，不强迫静止人物全程走动。
- 仅用于视频：实体电影镜头观感、180度快门模糊、24fps、稳定运动及环境实景声可成为一组相容选择；高速冻结、手持、对白/配乐或字幕按本片目的调整。静态资产不含这些视频控制项。

静态人物/场景/道具的固定生成写法见[资产提示词](asset-prompts.md)，不把动态/声音要求移入生图。上述材料为表达参考，实际模型响应仍需真实样片验证。
