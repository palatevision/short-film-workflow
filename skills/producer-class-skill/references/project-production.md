# 项目判断与制作协作

项目路线、资源、职责、排期或团队反馈影响推进时读。方法结合已存课程与2026-10-30收录讨论，来源和限度见[课程证据](course-evidence.md)；当前项目事实与已定权限优先。

## 先确认这次必须保住什么

从已有资料提取表达/用途、观看或采用需求、时间/预算/资源和执行能力；按[内容目标与受众](content-goals-and-audience.md)确定主要结果。个人实验可以不融资、不盈利；正式项目按真实交付约定判断。课程“立项”是项目条件判断，不替代行政或合同程序。

品质、预算、周期冲突时，列不能丢的效果、已固定约束和可缩范围，比较缩规模、复用、换路线、延期或追加资源的具体影响。更多预算不保证品质，长周期也有成本；不能把三角示意当普遍只能三选二。信息足够就给推荐方案及代价，关键条件未知才问，不把整张立项表交给用户。

## 让决定、输入与下一步能被接住

保住已定故事/用途、全片感觉和采用标准，使风格、资产、分镜、生成与剪辑围绕它们选择。有依据的新发现可修方案，说清改变与下游影响，更新同一份采用依据；一以贯之不是固守已知错误。

分清谁提出、谁决定、谁执行，以实际能力与结果责任划分，不按头衔/名气定唯一权力中心。课堂制片/制作称谓是职责说明，具体项目可兼任；不要求凑部门或固定导演/制片/制作三人审批。岗位不全时，摄影、整体视觉、声音/剪辑和生产组织的判断仍要有人承担：资产与镜头选择的差别按[六维组装](shot-assembly.md)，摄影按[摄影库](photography.md)，声音与阶段衔接按[制作联用](production-and-learning.md)。

开始或重要变化时，对齐核心目标、职责/决定范围、当前采用版及执行所需信息。不是所有问题都上交一个人，也不为小事反复开会。边界模糊且影响推进时找负责人；紧急处置限已有授权和可逆范围，告知并留依据，不能以“没时间”扩张权限。

## 把意见变成可执行反馈

先看本次要修正继续、调整分工还是交给决定人。分开自己观察、他人原话、创作偏好和原因猜测，再用下面的关系形成一条能行动的反馈：

**采用版/具体差异 → 对目标或下游的影响 → 下一步与复查依据。**

例如：“当前B图把左手的杯子改到了右手，前镜仍是左手，所以接镜跳手。先保留B图其他部分，只把持杯状态改回左手，再与前镜末帧对照。”这是助手示例，不能当真实项目已发现的问题。

“不好看、缺高级感、态度不好”都还不是可定位事实。画面问题落到身份、构图、受光、材质或动作差异；审美偏好可用少量对照方向澄清，不能伪装为唯一正确标准。先排输入/采用标准变化，再断言是某人或某工具失误。转达意见不等于代替创作负责人拍板；管理问题和创作取舍分别找有职责的人。

用户只说“不对劲”时不要求其先做专业诊断，助手从实际资料找差异；若缺媒体，只给初步假设和决定修法所需的最小缺口。节奏/接点/声画问题先看现有剪辑；源资产身份/状态错先回资产；事件缺失回分镜；语言歧义改词。给首要修法及影响，不无差别全片重做。

## 排期看有效采用与依赖

由截止时间倒排关键依赖，为剪辑、声音、修改和交付留余量；可以边做边剪就滚动核验。任务说明输入、执行/决定人和采用依据，个人项目直接用镜头记录。按适合阶段检查已采用、待修和阻塞；累计生成条数/秒数不等于可交付成果。

筛选/修改前对齐本轮要解决什么、哪些不能丢、何时复查。已满足本镜/本场职责就进入下游，缺具体反应/接镜才补。进度落后先查瓶颈，选缩范围、调资源或改排期，不自动把欠量压到次日。到约定时间/成本边界仍未满足，提出保留目标的备用表达与代价，由有权决定的人选择。

临近交付核给谁、用在哪、版本/规格、采用媒体和来源是否齐；轻量预演、测试与交接记录见[制作联用](production-and-learning.md)。自用按用户目的完成，宣传/投稿/发布等外部动作另按当前授权，不由课堂提及自动触发。

## 合作沟通看真实匹配

区分本轮要继续讨论、确认具体条件还是长期合作，明确双方实际需求、能提供的东西及缺口。用相关作品、实际职责、已有流程或可验证的小方案说明能力，缺的部分说明补法，不虚构资源和履历。对方愿意见面、气氛好、聊得久都不等于已成交。

多人出席先对齐回答范围和未定条件；根据新反馈调整方案，最后记清达成/分歧/下一步。选人看相关作品/合作表现、可用时间、交接和允许变化，不能从一次聊天猜完整人格。需要时以已授权的小范围协作判断实际匹配，不为每个项目强制试岗。

项目结束保留采用资产与父本、词/设置、流程版本、关键取舍及有效/失败条件，按[制作联用](production-and-learning.md)接续；不另建竞争记录。个人与小团队按规模维护，关系/条件只保留继续合作所需信息，不强制CRM或飞书多表。
