# 制作人班skill

承接当前项目对话、权威稿和用户最新确认，从正在做的环节继续；选择适合的专业Skill主导，把课程判断合进同一份交付。按任务读必要参考，不要求所有影视任务先经过Jack，也不同时维护竞争稿。

## 先承接，再推进

- 从已有资料取得本轮任务、已确认的故事/风格/资产、生成方式和权限。用户只改一镜或已在剪辑，就处理该范围，不重做立项/全片分镜。
- 剧情、身份、对白、参考映射等缺口若会改变结果，集中问真正缺的一点；同时推进不依赖它的部分。普通摄影与表达选择主动给方案，探索稿清楚标提案，不把未知写成事实。
- 默认故事→完整分镜草案→逐镜讨论→按需资产/提示词→样片反馈。已有输入满足下一步就交实际稿，不只介绍方法；不要自动越到用户尚未要求的阶段。
- 主动对齐全片感觉和关键镜头，带具体选择说明对观众所知/情绪的影响；已定方向直接承接。常规参数不让用户逐项填表。

## 本轮交付与继续条件

先从上下文取得当前任务、采用版、实际输入与可改范围。输入足够就给表中本轮结果；不够时先推进独立部分，只问会改变方案的缺口。完成前对照这次目标检查因果/信息、参考与连续性、摄影/声音及真实执行状态。需要修订时回到有证据的缺口，不默认全部重做；达到本轮采用条件就进入用户已要求的下一步。

## 视频提示词的固定交付约定

生成词先读唯一现行的[共同格式](references/prompt-delivery.md)：**时长、画幅、风格、参考图绑定与初态、动作、景别、摄影参数、声音、必要约束**。挂图顺序、镜号和预计剪辑长度在复制段外；绑定置前，落幅并入最后动作段，景别单列，不输出01/02章节编号。相机品牌/型号可选，摄影关系仍清楚。

- 每个可独立复制的镜头写全已定风格，不写“同上”。颗粒、光色、远距长焦与近身广角等按[镜头语言](references/cinematography-language.md)选择相容内容；摄影表达融入本镜，不作为独立命名风格或整套默认前后缀。
- 生成正文写可见/可听内容，导演目的和流程说明在外。精简重复限定，写足必要动作顺序、协同、持物、接触/遮挡、停顿和末态；时长装不下就给延长/拆镜取舍，不偷省关键动作。
- 写实新人物/场景没有其他已定画风时按[固定资产提示词](references/asset-prompts.md)写完整内容；保留已有资产、状态与已确认其他风格。图像任务去掉视频专用项，只列真实参考，不编图号或强制首/尾帧。
- 沿用已定逐镜/多图方式。写词、修稿与实际生成分开，后者按当前授权和工具能力执行；不把方案当已生成媒体。

## 交付前检查真正影响结果的地方

核动作负载、摄影与清晰范围、身份/视线/持物、参考初态和前末后初。按证据选修复环节：节奏/接点/声画缺口先看现有剪辑与声音；源资产身份/状态错误回资产；事件缺失回分镜；执行歧义才改词。能用的部分保留，只动缺口与必要衔接。

没有样片时说明初步判断，索取能决定修法的最少片段/关键帧、原词或参考；不因“质感不好”直接归因模型或长提示词。[装配器](scripts/assemble_video_prompt.py)只辅助字段检查，用户不必填写JSON；字段、人工内容复核、模型实际效果分别验收。
