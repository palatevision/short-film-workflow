# Seedance 2.5完整示例：门口交钥匙

助手原创的12秒单镜练习，仅作格式和适配检查；资产与人物均为虚构，未上传或生成媒体，不是当前《剪影师》生产稿。参考[2.5适配](../references/seedance-2-5.md)，最终栏目遵守[统一规范](../references/prompt-delivery.md)。

假设实际素材顺序：图片1林岚人物造型；图片2周野人物造型；图片3走廊空间；音频1林岚音色。实际使用时须用真实素材替换假设槽位，并按所选平台确认编号与绑定。模型选Seedance 2.5参考生成，时长12秒、16:9；这是计划要求，未操作平台控件。

```text
时长：12秒。
画幅：16:9。

风格：现代悬疑写实，低饱和灰蓝与自然肤色，布料、木门和金属保持真实材质，柔和颗粒、克制反光。走廊顶灯提供偏冷的柔光，门缝透出少量暖光；明暗有层次，双手与钥匙环清楚可辨。

参考图绑定与初态：图片1仅绑定林岚的身份和服装，图片2仅绑定周野的身份和服装；图片3提供走廊、木门及灯位关系。音频1只参考林岚的音色，不沿用其原话或背景声。林岚在画面左侧，身后半步是关闭的木门；她面向画面右侧的周野，右手捏住带一把钥匙的金属钥匙环，垂在腰前，左手空着。周野面向她站在一米外，双手空着。镜头开始时两人及木门均在画面中。

动作：
0—3秒：林岚看向周野，右手将钥匙环抬至两人腰间的位置。1—2.5秒，她低声说出下方唯一一句对白；周野看向她的右手，保持闭口。
3—6秒：林岚右手向周野递出钥匙环，手指仍捏着环。周野伸出左手，掌心向上托住钥匙；待钥匙落在他左掌后，他收拢手指握住钥匙环，林岚才松开右手并收回。钥匙交接始终在两人之间、无遮挡处完成。
6—9秒：周野把握着钥匙环的左手放低至腰侧，目光转回林岚。林岚转身面向身后的木门，抬起左手按下门把，向室内推开门。
9—12秒：林岚侧身跨进门内，周野停在门外，左手始终握着同一枚钥匙环。最后门保持半开，林岚在门内暖光中回头看向周野；周野留在右侧前景。镜头停留半秒，门内的林岚和门外的周野都保持可辨。

景别：全程中全景，画面覆盖两人的头部至膝部、完整交接区域和木门。

摄影参数：平视机位，从走廊斜侧面对两人，全画幅等效35mm视野；固定机位与画框，无内部切镜。中等景深，前中景双手、人物面孔与门口都在可辨清晰范围；不在交接过程中拉焦。两人分居画面左右，门位于左侧后景，交接区域留在画面中央下方。

声音：林岚唯一一句对白为“拿着，别丢。”，音色参考音频1；对应动作中的1—2.5秒。钥匙轻碰、衣料摩擦、门把轻响与低声走廊底噪，无配乐、无旁白。周野全程不说话。

必要约束：保持两人的身份、服装和身高关系；钥匙只由林岚右手交到周野左手，松手前已被接稳，之后始终留在周野左手。人物站位随上述行动改变，灯源位置保持；全程连续单镜，无字幕。
```

检查案例：若删成“林岚递钥匙后进门”，会失去左/右手归属、先接稳再松手、对白时机和末态。若复制为“所有道具位置全程不变”，又会封死交接。当前文本保留这些因果控制，同时没有新增五段编号、独立落幅章节、强制首尾帧或用户填表。这里只验证了文本设计和格式，不证明模型能稳定执行交接。
