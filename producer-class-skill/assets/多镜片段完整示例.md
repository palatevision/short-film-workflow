# 多镜片段完整示例

这是虚构生活短片的离线格式演示，采用文生视频，无真实参考图/素材，没有生成或验收媒体。12秒三镜是本例提案，不是默认规格。仅在项目已选择多镜片段生成时使用；若按单镜生成，各镜仍要分别给完整提示词，不让用户拆本例拼词。内部装配器不验证多镜时序，本例按规范手工组织并作作者检查。

## 资产与设置

无参考资产；两人和房间由正文描述。建议平台控件为12秒、16:9，实际是否支持这种时长、多镜和音频需按目标工具核验。当前没有指定工具，不冒称可以提交。

## 完整复制段

镜号SEQ-EX01（A01、A02、A03）。公共风格与绑定置前，各镜摄影不同因此放在对应时间段内；切点就地写承接，落幅并入末镜动作。

```text
时长：生成12秒
画幅：16:9

风格：写实生活短片，自然皮肤与织物纹理，浅灰和木色，窗户位于房间后侧，柔和日光照入，阴影方向统一。

参考图绑定与初态：无参考图。短发男子穿深色外套，右手拿一只无字牛皮纸信封，起始在左侧门外。齐肩发女子穿灰色毛衣，坐在木桌右侧，双手放在桌边。男子对应的空椅在桌子左侧，两人视线轴沿桌子左右延伸，三个机位均位于桌子前侧的同一半空间。门、木桌、窗户的位置固定；本段男子进门落座，将信封推到女子面前。

动作：
A01，0—4秒。
门被男子左手推开，男子从画面左侧进入，左手松开门，右手一直拿着信封，走到木桌左侧的空椅旁；女子留在原座位，目光跟随男子。
景别：室内全景，两人及门桌椅可辨。
摄影参数：
  机位：房间前侧，胸口高度平视
  等效焦段／视野：全画幅等效28mm
  光圈／景深：中深景深
  对焦：覆盖男子与桌边女子
  构图：门在左、桌面居中、女子在右
  运镜：相机固定
声音：连续室内底噪，门轴轻响与男子脚步，无对白、无配乐。

A02，4—8秒，切镜。承接男子抵达空椅旁的位置和左手准备拉椅的动作，人物不交换座位。
承接男子来到椅旁；他左手把椅子向后拉出，坐下，右手把信封平放桌上；女子保持坐姿，目光从男子转到桌面。
景别：男子中景，女子右肩在近前景。
摄影参数：
  机位：女子身后右侧，略高于桌面平视男子，保持原轴线一侧
  等效焦段／视野：全画幅等效50mm
  光圈／景深：中等景深
  对焦：男子与其右手
  构图：女子肩部只占右下角，男子与信封不被遮住
  运镜：相机固定
声音：承接室内底噪，椅脚摩擦声、落座衣料声和信封落桌声，无对白、无配乐。

A03，8—12秒，切镜。在信封落桌时切，以同一桌面位置和落桌声承接，不重复放下动作。
信封已平放在桌面男子一侧；男子右手压住信封后沿，向女子方向平稳推过去，信封在女子手前停住；女子双手仍在桌边，没有接起信封；男子右手松开，收回自己一侧。结束时信封停在女子手前，女子尚未接起；相机固定，焦点留在信封，停留至片段结束。
景别：桌面、信封与两人手部特写。
摄影参数：
  机位：桌面上方斜俯拍，从原轴线同侧看桌面
  等效焦段／视野：全画幅等效85mm
  光圈／景深：中等景深
  对焦：随信封移动至女子手前并停住
  构图：只取信封和桌边手部，不见面部
  运镜：相机固定，仅焦点跟随信封
声音：承接室内底噪，纸张摩擦木桌的声音，信封停下后只留底噪，无对白、无配乐。

必要约束：不生成字幕、画外配乐或新增人物；信封表面无文字。手部接触并推动信封，信封不自行滑动。
同一男子、女子、衣着、房间布局和窗光延续；信封始终是同一只。允许门打开、椅子拉出、男子落座及信封按本段动作移动；不以“全程不变”封死这些变化。
```

## 作者检查

总时间覆盖0—12秒，无重叠/空档；每镜写动作、景别、机位/视野、景深、焦点、构图、运镜和声音；全局风格/身份只完整写一次。切点有具体承接，信封放下与推送分镜衔接，落幅有等待状态。实际动作速度、视线/轴线执行和音画结果需要媒体验证，本例不是模型行为测试。
