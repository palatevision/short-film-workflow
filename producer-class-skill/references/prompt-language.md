# 给模型的提示词：可见内容与具体动作

2026-10-23用户要求：保留明确交付格式，正文尽量少放对人解释的语言，参考“我的AI都市传说”胃头女资产的清楚组织方式。以下是写法与诊断方法，不是对生成质量的保证。

## 分清说明和执行正文

本页的分时动作、时长和声音规则用于视频；图片只复用可见内容与精简原则，按图片任务自己的结构交付。静态资产不套视频九栏目，也不加入时长、持续运镜或声音，具体见[静态资产](asset-prompts.md)。

镜头职责、表达什么、为什么这样拍、补什么因果、建议/非投产/验收状态、模型不支持时怎么办等，只在复制段外有必要时简短说明；用户只要提示词时省去无关说明。复制段保留[统一栏目](prompt-delivery.md)，内容只写需要出现的形状、材质、光线、位置、动作、摄影、声音和必要保持项。

“时长/画幅/动作/景别”等简单标签保留，镜号放复制段外；绑定置前，落幅接在最后动作段，按共同格式交付；避免在其内容里再写“请理解”“目的是”“这是为了解决”。剧情对白、画面中明确要求出现的文字不受这条限制，不因词语表面像说明就删掉它们。

| 给人讨论时的说法 | 转成可见或可听的描述（例子，非当前项目改稿） |
| --- | --- |
| 表达压迫感，让观众觉得他逃不掉 | 人物后退至墙前停住，两侧墙面挤入画面；近距离低机位，保持人物与墙面可辨 |
| 交代实体与影子的因果关系 | 围巾实体在画面左侧，轮廓相符的墙影在右侧；剪刀刀口贴近墙面，仅围住墙上的围巾影。合拢后，画面左侧围巾向下坠落 |

| 这是给后期配音的意图，模型不支持就后期做 | 正文写“声音：衣料轻响、短促吸气、无对白”；音频能力和后期安排放正文外 |

抽象词不是一律无效。少量“冷峻、轻盈、紧张”等可作风格锚点，但必须有支持它的摄影、光色或动作，不让模型独自补一整套叙事逻辑。不要为了删抽象词而丢失故事节拍、必要摄影数字或原本明确的角色关系。

## 精简的是无效文字，核心信息仍完整

- 每镜突出一个主要事件，明确谁在什么位置对什么做了什么，起止状态清楚；必要连续动作可以保留，不设固定字数上限。
- 优先描述应出现的结果，如“固定机位”“嘴缝闭合”“画面仅见双手”；关键排除项按目标模型支持程度保留或转换，不机械堆长串“不要”。
- 图生视频复用已确认的外观锚点，优先写本镜动作、摄影变化和必要连续性；不反复逐件重写源图中所有装饰。多图必须明确各图用途、哪个主体移动及相互位置，不能把角色设定图当作已确定机位的首帧。
- 参考图和文字不相容时，先解决源图的姿态/构图/状态或调整动作，不靠再加“严格保持”掩盖冲突。
- 背景人物或环境活动影响本镜观感/信息时，写可见的持续动作和相对位置，如“后景两名店员继续收盘，保持在柜台后”；主角动作与背景活动分别明确。沿用已定事件，不为了避免静止擅加新戏，也不为无关画外对象加词。10月25日上午转写16:09的背景冻结与补动作是讲师经验，没有原词/样片对照；不据此承诺加一句就能解决。
- 光线、材质与肤质应先在资产阶段建立。已生成资产和视频保持已选风格，后续补镜不因本规则自动重做或换色。

## 限定精简，保留有效基底

- 用户2026-10-23补充：限定过多可能增加理解负担，后续优先精简明确。视为写作偏好与待比较的经验，不写成所有模型的确定能力上限。
- 保留主体、关键动作/空间、已确认风格及必要摄影/声音；同一镜内同一要求只写一次；跨镜仍完整带入全片已定的有效风格基底，不把去重理解为让用户查找“同上”。删除重复外观清单、无关画外对象、全套通用禁止项和多余的精确数字，约束集中到本镜易错点。
- 用可见目标代替成串否定，例如“刀口之间是带墙纹的平面投影”，不反复追加“不能剪实物、绝对不能碰实物”。参考构图与动作冲突时先解决冲突。
- 统一栏目照常保留，内容按需简写；“精简”不等于丢景别、关键摄影、身份锚点，或把用户已认可的固定资产基底换成笼统的“电影感”。

## 动作细节写足，按时间形成目标画面

用户2026-10-23提供《我的AI都市传说》8秒雨伞转身补镜原文，明确偏好：少写给人看的解释，人物动作和细节该有的都要有。上一轮06/09示例虽栏目齐全，用户认为画面动作过于简短笼统；修正的是行动组织，不能再把“精简”理解为压缩动作段。

- 从明确初态写到落点：站位和朝向、视线/手部起点、动作触发、先后/并行关系、速度/幅度、停顿及末态。按取景和目标选必要细节，不逐镜机械枚举全身关节。
- 一个主要事件可以有多项协同子动作。手脚/髋肩转动、视线、呼吸、道具持握和跟随关系共同决定画面时，应具体保留，不压成“她转身”“他放钱说话”。动作细节用于落实已定表演，不擅加笑、哭、挑眉等无依据的新情节或情绪。
- 写清全过程：哪只手拿什么，何时接触/松开，人物与道具相对位置如何改变；遮挡必须说明遮挡物、被遮区域、摄影机方向，以及运动后仍怎样覆盖。不能只写开头挡住或尾帧正确。
- 参考绑定区分身份、造型、地理、镜头方向与真实起始帧；只借外观/角度的参考不默认成为首帧。相机路径与主体运动分别写，连续镜头的时间段标为阶段/节拍，避免被“Shot 1/2/3”误读成切镜。
- 简单动作可用自然先后顺序；多个协同动作、停顿、对白或遮挡变化需要时再按时间段组织。不固定每镜字数、秒数或必须分三段；写出的动作要能在生成时长内以所需速度完成，并给必要反应/停顿留时间。
- 时长不足时优先提出延长生成或拆镜方案并说明衔接，不靠删掉关键动作、偷省交接或无意加速来凑时长。生成时长与成片取用时长分开；时间标记不保证模型逐秒执行。

示例（用户原文节选）：“04号朝自己的左肩转，脚和髋先转、肩再跟上，俯视为清楚的逆时针；男主保持她身后半步，不绕行。”结合伞布倾斜/半合期间持续遮头、男主右手始终持同一束花，形成可见的协同行动。可迁移的是动作顺序、空间和持续关系，不能把原文重复三次风格块/禁令、特定色彩或器材当通用要求。

只在观看了实际输出后判断动作链是否达成。本次来源是用户贴出的历史提示词及其偏好说明，没有对应雨伞视频，不宣称该长提示词已逐项验证、必然优于短词或能确保全帧遮挡。

目标为Seedance 2.5时读[官方适配参考](seedance-2-5.md)。用户2026-10-25强调复杂调度需要足够详细的词：按控制关系展开信息量，精简不删关键动作/声音/连续性；具体素材用途、时序和任务入口先分清。准确参考可以承载已有动作，正文突出本次差异与易错点，不能为了概括丢掉用户已定交接、持物或遮挡。实际需要多步骤时提出方案，不因模型升级强制所有镜头加长或改生成方式。

## 出片有偏差时怎样定位

先按实际提示词、挂载参考、设置和样片分辨：①抽样与模型能力；②语言歧义/冲突；③资产质量或参考映射；④动作、遮挡与物理变化过载；⑤平台设置/剪辑承接。不能从一次失败确定是哪一类，也不许把多跑几次当作唯一办法。

质感问题先对照原始人物/场景资产与输出：材料反射是否像实物、皮肤是否蜡亮、灯光层次/接触阴影/空间是否可信，再看生成后的变化。资产本身已有明显问题时，优先提出修资产的方案；不默认期待视频阶段的“电影感”、机身名称或分辨率词补救。画面功能清楚与质感获认可分别判断。

用户认为某因素更重要时，作为创作者验收与下一轮验证优先级记录，不能用“原因很多”冲淡反馈；同时区分观感判断与已控制变量的因果结果。

同一提示词在模型更新后变样，先记录当前版本、参考和实际设置，用本项目代表镜头比较；把旧词当基线，不把历史成功等同新版本仍适用。老师10月25日上午13:12—17:20提到的字数与“更可控”解释是个人经验，不设全模型字数门槛或底层机制结论。

小问题按[现有诊断模块](production-and-learning.md)一次只改一类关键变量；工具支持时固定种子等可控条件。若原提示词本身根本矛盾，先整体纠正矛盾再建立比较基线，不能为了单变量而保留坏基线。没有媒体和账单时不报通过率、积分结论或已验证效果。

## 来源与限度

- 当轮用户明确反馈是本规则依据。“我的AI都市传说”聊天中`胃头人04_天台红裙女性`完整资产提示词已回读，消息id为`[内部消息定位已省略]`。结构为参考绑定→角色/服装→固定生物结构→材质→双栏视图→固定资产光线/质感；不能据此声称整片逐镜视频或效果已回看。
- [Runway Gen-4官方提示指南](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)建议具体物理动作、少会话解释，并在图生视频中重点描述运动；这是该模型指南，可作为通用写法参考，不等于已验证Seedance行为。
- [Amazon Nova Reel官方指南](https://docs.aws.amazon.com/nova/latest/userguide/prompting-video-generation.html)也区分画面描述与聊天命令。各模型字数、否定词及语法限制分别核对，不把某家限制升级为全模型规则。

## 下午补充：接住人物状态，避免强度词替代表演

2026-10-27下午原音02:25—02:45、02:47—03:04补证。长文戏分段时承接上一段末尾的人物状态、视线/持物、可见反应与触发事件；缺少前情时只补理解本镜所需的简短真实背景，落实到现有“参考图绑定与初态/动作”，不新增必须复制的剧情分析栏目。单镜足够就不附加前情。

若实际输出表演过满，比较减少“极度、崩溃”等强度词，改为当下可见反应、呼吸/停顿、声量与动作幅度；需要情绪转折则写起点→触发→反应，不用一个强标签覆盖整段。哭泣、大笑或强烈反应本来就是已定要求时照常保留，不统一降级人物感情。

讲师把“女儿死亡”改写成“女儿失踪”控制模型的做法保留在证据层，不改我们权威剧本的事实。优先去掉不必要的诱导性背景、直接写所需反应；确需替代情境作表演测试，单独标候选并核不得改变对白、道具、动作因果及后续剧情。其“压缩重写”也区分两种：给模型最少必要前情可以压缩表述；删剧情/改对白则回故事负责人和用户已定边界，不能为了接情绪静默删戏。可选准备段/重复对白留在生产计划外显说明，核实际剪入区间、声画与情绪，不误放进正式成片。

### 复杂运镜讲清过程中的画面变化

摄影机转向/环绕与人物移动分别写。除相机路径，还写运动中谁到前/后景、人物自身朝向、何物被带入/遮挡、谁从画面哪侧出画，以及最后的景别与构图；只补本镜必须控制的空间，不堆所有物体。绑定人物/场景/关键道具和已认可音色时说明用途，符合当前入口能力；声音约束写过仍需检查结果。

参数不足以控制时，补可见效果，例如“近处肩背仅占左缘并柔化、主体眼睛清楚、远处灯点成柔和光斑”，保留必要焦段/光圈视觉参考而不靠数字独撑。具体格式不变：每镜完整全片风格、独立景别、动作末段落幅与摄影/声音。讲师的重复强调、尝试次数和不常用Agent的习惯，不变成通用长词配额或停用其他Skill；某段可容许的非关键偏差不覆盖本项目硬约束。
