# 分镜到提示词：用六维组装画面

用途：已有资产或分镜事件，需要把它写成清楚、可直接复制的生成提示词。与[交付格式](prompt-delivery.md)一起用；原始点子或故事需求仍先做故事，不抢跑写词。

## 先锁住这镜已经决定的事

承接当前镜号、时长、画幅、资产身份/用途、事件顺序、起止状态、已选风格和声音。已有信息直接用；只缺摄影写法时助手提出方案，正文外标建议。不把“润色”理解为另编人物、改动作因果、加台词或新增参考图。补充会改变镜头职责/叙事时先提出来讨论。

资料不全时，先区分可建议的摄影和必须明确的剧情事实。探索稿可标提案；最终投产稿不把未知身份、占位台词或版本矛盾写成已确认事实。

## 从镜头事件展开六维，再落入统一栏目

六维是组装时的思路，不要求给用户再交一张六维填表。

| 维度 | 从原稿补清什么 | 写进我们的哪里 |
| --- | --- | --- |
| 内容 | 谁的初态、具体动作链/协同动作与反应、先后/并行、道具与环境变化 | 动作、声音、必要约束 |
| 空间 | 人物/物件相对位置、前中后景、谁动谁固定、接触与遮挡 | 参考图绑定与初态、动作、摄影参数 |
| 景别 | 观众必须读到的范围、主体占比；需要时写起止变化 | 景别、摄影参数 |
| 角度 | 看主体哪一侧、机位高度/俯仰、视点；人物左右与屏幕左右分开 | 摄影参数 |
| 运镜 | 相机路径与稳定性；位移/转向/变焦/拉焦各有什么变化 | 动作中的相机阶段、摄影参数 |
| 落幅 | 最后人物/物件在哪、动作到哪、相机是否停、最后什么清晰；与下一镜如何衔接 | 动作末段、摄影参数、必要约束 |

按当前事件在六维间来回推敲，不强制六项的推理顺序。按[动作链与节拍](prompt-language.md)把构成目标画面的身体/手部、持物、持续遮挡、速度和停顿写足；一个主要事件可以包含多项协同子动作，不压成“她转身”一类概括句。时长不足先讨论延长或拆镜，不偷省关键交接。先明确要看清什么，再挑摄影参数；不为了凑术语增加运镜或环境变形。依据景别、距离、视野和清晰范围选相容参数，机身品牌可不限定。

导演目的用于内部判断，例如“让人意识到他决定离开”，进入复制段时落实成手拿钥匙、动作停顿、视线等可见细节。不要把目的句直接塞入模型正文。

声音的发声时刻、远近/遮挡和进退与动作、空间和切点相容；需要声音承担信息或诊断听感时读[声音叙事](sound-design.md)，只把本镜实际可听内容集中写进“声音”。

最终依共同格式输出：资产清单→时长/画幅、风格、参考图绑定与初态、动作、景别、摄影参数、声音、必要约束完整复制段；动作末段包含落幅，六维内容进入相应栏目，不另加一套六维复制模板。单镜全部写全，声音不在多处重复；平台时长/比例等控件另列，不以正文文字代替真实设置。完整实例见[分镜到提示词示例](../assets/分镜到提示词完整示例.md)，不是当前片子的投产替代稿。

## 把观感落到同一镜里

用户给的是“体贴/压迫/关系疏远”时，先从已定故事选择一次能被看见的行为和对方回应，再决定怎样看清它；不直接把性格词当动作。比如已有递糖后被拒的事件，就写递到哪里、对方怎样拒绝、手是否收回、接下来怎样调整，保留故事原有反应，不凭空补暖心剧情。

摄影选择跟随这个事件：需要读双方反应就保留合适的同框或组接，需要读交接就让手/道具清楚，动作结束把关系变化落在可见末态。抽象目标不必在每镜同时变成色温、浅景深、推镜和配乐；只选真正有帮助的手段，再按现行标签交完整词。

## 同一场事件的上下文与生成单位

孟柯2026-10-24上午转写01:06:58、01:14:47—01:16:37、01:46:28—01:49:47补充：先明确一场戏里各人的任务、行动/反应和变化，再选择观看角度。内部可写心理/关系判断；复制正文继续转成可见表演、必要动作链、持物/遮挡及声音，不把解释性台词或抽象目的堆进生成词。

人物暂时不入画，仍可能在场活动或发声。需要时在同一事件进程中保持画外人、物与声音状态；按主次取舍，不为所有画外对象加词。逐镜更换角度不能无故改掉同一接触/交接过程。

按当前已定生成方式选择控制单位：单镜保留逐镜复制段；多镜片段确有价值且模型支持时，明确时间段和切点，不能把段内阶段自动当切镜。关键关系参考可复用；不因课堂以30秒举例就改时长或全片流程。当前内部装配器schema 4按单镜字段输出用户确认的简单栏目，不验证多镜段落的时序；确需多镜交付时保留逐镜完整信息，由模型适配按已核验平台能力组织，在同一权威文件交付。

讲师还提出可选路径：先生成同场全景活动、检查动作与关系，再取帧安排其他视角。这是复杂互动时可以比较的事件底稿方案，尚无本课完整生成链或我们的实测；不新增为每片/每镜首尾帧前置，不宣称派生镜头会自动一致。用户已有多图直出保持，具体失败时才评估是否需要。

## 连续镜头：安排注意力怎样接力

2026-10-25导演思维课件13—16、20—23页，补充六维中的内容/空间/运镜/落幅。用户要单镜头叙述、或走位很多却没看懂时，在现有分镜中先写内部进程：注意谁/什么→哪个动作、视线、声音或空间揭示触发转移→观众新看见什么→最后停在哪里。

把它落实到人物先后/协同动作、遮挡/接触、进出画面和相对位置；摄影机根据实际观看任务选择跟、停、转向、改变距离，焦点/声音也能接力。相机可全程固定，注意力仍可转移；运动依据可以来自环境或画外信息，不限于跟人走。同一事件还看双方反应怎样变化：一方完成带路/交涉，另一方从疑惑到理解或态度改变；按已有剧情落实到停步、视线、回应等动作，不只写摄影机路线。（上午转写01:25:24—01:33:52补证）明确每次变化在何时发生，不为展示术语而连续加运镜。

需要节奏时比较动作速度、停顿、景别/空间揭示、光线过渡和声音密度，不强迫每段全变，也不把灯光任意跳色当叙事。末态沿用现行规范，写进最后动作时间段。空镜/停留可以承担等待、时间感与氛围，不机械要求每个镜头都让关系转折。

是否连续完成，按它能保留的动作因果、同时性、空间关系、表演呼吸，与剪辑方案比较。再看生成时长、多人互动、遮挡、空间覆盖和返工可控性；连续复杂过载时提出拆镜/备用视角，保留必须被理解的关系，不强加一镜到底或“能剪就禁止长镜头”。课件90秒、两个人/一个场景是练习条件，不覆盖当前项目生成方式。上午01:11:00—01:14:14明确把连续叙述训练用于普通短单镜；能用静止表达的镜头照常静止。

下午43:00—46:30口述其2.5用法更强调角度、切点和时间段，2.0曾给更多自由发挥。只把它作为按版本/任务核写法的案例：复杂调度把事件和摄影写清，简单单镜不凑镜数；30秒/8—10镜或MV12秒/8—9镜都不是默认规格。写到0.1秒或生成偏差半秒是其经验，不等于接口提供帧级精控；实际卡点回时间线修。本课无完整原始词/挂图/设置/输出文件链，不能声称照词就能复现。

## 润色后核对什么

1. 回对原稿：人物、资产身份、核心动作、顺序、起止状态、对白和已定风格有无被改；新增细节是画面实现还是擅自改戏。10月25日下午24:00—26:50、01:05:02—01:06:40补证：看到实际结果后，标出GPT稿中不需要的动作/表演并删改，只保留支撑本镜的内容；缺歌词口型、灯牌变化等控制时再补对应具体描述，不把润色稿直接当定稿。
2. 连看前末/后初：视线、出入画方向、持物与动作阶段是否相容；允许有依据的省略，不强求同画框无缝续拍。
3. 找实际矛盾：要读清的物件是否被景深/遮挡藏掉，相机是否被要求同时固定又移动，变化是否又被“全程不变”禁止。
4. 生成后比较目标与偏差：核原资产、参考映射、事件与语言/设置，按证据选修复层。节奏/接点可先用现有剪辑；身份或道具状态错误回资产，事件缺失回分镜，执行歧义改词。只动首要缺口与必要衔接，不从一次失败认定抽样问题。

## 陈坤老师工作流：目前知道与还不知道的

2026-10-23用户现场转述：老师把自己的角色/场景资产提供给GPT，自己写每个镜头发生什么，再让GPT润色成分镜提示词。可观察的人机分工是导演先给资产与镜头事件，GPT辅助生成表达；六维图提供组织画面的思路。

尚未拿到同一镜头的原稿、GPT稿、失败样片与修改稿，因此不声称还原了老师的隐藏指令、实际节点连法、参数补充者或修正顺序。上面的组装/核对步骤是我们结合课程和现有约定的做法；也不据此限制我们用AI辅助故事创作。

后续优先取一个真实失败链：原稿→GPT输出→实际结果→老师改哪里及判断依据。新增证据再修条件，不把猜测变成“老师标准流程”。
