# 从案例融通成方法

用户2026-10-23明确：通用方法应是案例内容的融会贯通。收录不是按讲师逐份复述，也不是把案例元素改名后套用；要让以后一句画面需求能触发合适的判断。

## 提炼判断，保留证据边界

读案例时先找：当时的处境/限制、需要解决的观众信息或制作问题、作者实际采用的选择、这个选择可能解决什么、换一个条件为何要改。把案例与已有课程、其他案例和自己项目的真实结果交叉比较，区分共同机制与题材/风格/工具差异。不要为了合并而抹平讲师分歧。

可复用条目用“何时用→判断依据→怎样做→看什么结果→何时失效”组织，并附来源位置和验证状态。单例可以形成有条件的工作假设，不冒充普遍定律；不要求凑齐固定数量案例。课程明说、案例可见文本、助手解释、实际制作效果分别标明。文档排列只能证明文档结构，不能证明老师真实操作的先后、工具或尝试次数。

新增材料先与已有主题比较：相同结论补证据，有不同条件补边界，有冲突保留情境，实质新判断才加方法。案例全文和版本疑点留在项目证据层，Skill只保留能改变以后决策的部分。已有观点获得第二个出处不等于经过效果验证。

## 只有录音，也能开始沉淀

用户可直接给文件，不要求先听课、挑重点或补随堂笔记。收到后按实际可用工具处理；有transcribe等可用模块时负责本地转写，Auday仅在已安装、用户要接入且就绪时按其Skill读取，不把它设为录音处理的前置。没有文件时只记录安排，不声称已经读到接下来两天的课。

- 保留原件/指纹、真实可探测时长和覆盖，按录音顺序读取转写；长文件可分段并保留原时间定位。摘要可导航，不代替完整可读转写。缺段、迟录和不可辨处明确列出；工具失败时报告已完成与卡点，不编转写。
- 主动寻找新的判断依据、完整案例、条件/反例和失败修正，不只摘老师的金句。分清讲解、学员问答、播放影片、课间和识别幻觉；说话人未核就不把全篇归给老师。没有原稿→修改→结果链，不宣称还原了完整工作流。
- 对会改变做法的否定词、数量、人物/工具名及因果顺序优先核原音/上下文；原转写与修正分开。未做原音听校时明确是识别稿阅读，不把未标错的文字当全部准确。网上资料只能补专业概念，不能补成老师说过的话。
- 遇到“看这张图/刚才这个镜头”，只提取口述可支持的判断；镜头内容、摄影实值、具体操作和实际效果等依赖屏幕的部分留待补。关键歧义无法消除就留候选，其余有充分依据的方法继续融合。
- 更新原主题：重复补来源，条件变化修边界，新判断才增条目。简报给真正新增/调整、来源覆盖和重要待核；不把整篇流水摘要塞进Skill，不要求用户补完所有疑点才能继续。

同源ASR、Auday总结和Highlights互相吻合可帮助定位，仍不是独立效果验证；课堂方法、助手迁移、文字检查和真实作品结果分别记录。用实际作品反馈继续校准，文件/字段验证不能代替成片验收。

## 已融通的判断与自然语言入口

以下结合Tom第一课、陈坤第二课、太阳日V2与既有资产经验；具体证据、段落定位及待核实项见[来源索引](course-evidence.md)。均未新增实际媒体验证。

| 用户当前问题 | 可调用的判断与做法 | 检查与边界 |
| --- | --- | --- |
| “这人变了，但看不出来” | 从人物当前冲突里找一次可见选择；用拿起/放回、靠近/离开等具体动作产生前后变化，关联目标、阻力和代价 | 动作要有动机和可见后果；客观事件镜头不必强造人物成长。接续[人物/信息判断](direction-and-information.md) |
| “两段怎么连起来” | 先明确要建立对照、同时性、因果还是情绪关联，再选相似动作、道具或构图组织剪辑；核前镜末与后镜初的动作阶段 | 形式相似不自动构成因果；该保留的时空区分不能被匹配剪辑抹掉 |
| “想让关系有变化，别靠台词解释” | 让距离、遮挡、入口和实际光源随人物行动发生可读变化，再以反应/声音承接；摄影服务这个变化 | 门/暖光不是通用答案；颜色不固定对应情绪，光变需有空间依据 |
| “换身、回忆、变装别串人” | 内部区分可见身体身份、意识/视点、时间层和造型状态；资产绑定锁外观，动作与对白按当下场景归属 | 普通单身份场景不额外增加字段。角色名冲突先留疑点，不能自行换脸。接续资产连续性主模块 |
| “道具接不上” | 追踪持有者、哪只手、位置和状态变化；关键因果写清接触、移动、放下的必要环节 | 可理解的省略可以保留，不为每个微动作加一镜；先找缺口，再决定改词、补资产还是剪辑 |
| “我想靠近、看清它” | 分开相机位移、方向转动、变焦收窄视野、焦点转移；确定要变的是空间关系、画框范围还是清晰对象，再选择摄影写法 | 可组合但各自写起止，不把推近/变焦/拉焦混为一词。接续[视觉规划](visual-planning-and-edit.md)与摄影库 |
| “把老师分镜变成我们能直接用的词” | 先统一当前项目的身份/时间/道具事实，承接镜头职责，再补时长、资产、起止和摄影/声音，按[共同格式](prompt-delivery.md)交付 | 分镜工作笔记中的内心解释、占位台词、未决版本不能直接进入复制段；导演理由在外，具体可见实现进正文 |

## 使用时融入当前项目

按请求选择最相关的判断，交给当前主用专业Skill落实到同一份剧本、分镜或提示词；不附赠另一套竞争模板，不让用户填写内部方法卡。摄影具体参数仍按当前项目职责选择，镜头语言与固定资产规范按已选范围使用。

收到真实输出后记录预期、实际变化和反例，再修适用条件。文字自检只验证结构和解释是否清楚，不能宣称已经复现老师影片质感。
